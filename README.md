# ☁️ Notes from the Cloud

A learning journal documenting my journey into cloud computing, AWS, Linux, infrastructure, security and AI deployment.

## About this repository

I'm a software developer with a background in frontend and full-stack development, currently expanding my knowledge into cloud computing and infrastructure.

As part of my AWS re/Start journey and independent practice, i'm exploring the technologies, concepts and tools that power applications beyond the code we write.

This repository is where i document that journey.

It contains my learning notes, command references, practical exercises, experiments and projects. The goal is to move beyond understanding concepts and develop the ability to apply them.

## What I'm learning

- **Linux:** Command-line fundamentals, file management, permissions and shell scripting.
- **AWS:** Cloud infrastructure, compute, storage and deployment.
- **Networking:** IP addressing, DNS, ports, protocols and network fundamentals.
- **Cloud Security:** IAM, access management and security best practices.
- **DevOps:** CI/CD, automation, monitoring and deployment workflows.
- **AI Deployment:** Exploring how AI applications and services can be deployed and managed in the cloud.

## Practical projects

I believe the best way to learn is by building.

As i progress, i'll be working on small projects that help me apply what I learn, document my decisions and understand how different cloud technologies work together.

Completed and ongoing projects will be documented in the `projects/` directory.

## Learning approach

This repository follows three principles:

1. **Learn:** Understand the underlying concepts.
2. **Build:** Apply the concepts through practical exercises and projects.
3. **Document:** Share the process, discoveries and lessons learned.
